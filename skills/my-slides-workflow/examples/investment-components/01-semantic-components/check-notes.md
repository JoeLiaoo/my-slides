# 检查备注

## 结构检查

- 三页均声明 `investment-components` / `content`，含 `slide-notes`。
- 页面分别使用 `investment-comparison`、`investment-thesis`、`investment-risk`。
- 比较页保留未披露数据，不写零或排名；风险页没有虚构概率或金额。
- 所有公司、客户访谈、来源和数据均为虚构。

## 视觉检查重点

- 桌面：比较卡片保持同宽，标题与脚注不与正文争夺层级。
- 手机竖屏：两张比较卡片、两项风险自然堆叠；最长公司名换行，页面无横向溢出。
- 手机横屏：正文仍完整可读，不靠缩小字体容纳内容；超出单页承载量时应拆页。
- 投资逻辑页只显示实际提供的判断、证据和条件；没有反证时不留空槽。
