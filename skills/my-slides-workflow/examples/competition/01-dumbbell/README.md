# example：同业哑铃对比

> 类别：竞争比较
> 目的：在同一指标下比较 5 家公司的两期差异。
> 关系类型：对比。
> 密度：中。
> 用途：竞争分析章节内的横评页；哑铃比并列柱更适合表达「基期 vs 当期」。

## 文件清单

```text
data.json         虚构市占率数据
wiki.md           假想 wiki 索引片段
report-excerpt.md 报告「同业对比」段落摘录
page.html         Design 页面：标题 + 内联 SVG 哑铃图 + 来源脚注 + 讲稿
check-notes.md    期望通过的检查与视觉自检
```

## 图是怎么画的

Design 没有图表库，图表写成页面里的内联 `<svg>`。横轴 0%–15% 对应 x = 260–1400（每 1% = 76px），每家公司一行，行距 90px：空心点是 2022，实心点是 2024，两点之间连线。换成真实数据时按同一比例重算圆心坐标，并同步改 `aria-label` 里的数值说明。

SVG 里的文字在编辑器里改不了，所以结论、副标题和来源都写在 SVG 外面；SVG 只放坐标轴、公司名和差值标签。
