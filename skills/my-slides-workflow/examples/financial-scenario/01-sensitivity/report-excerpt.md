# 报告段落摘录（财务情景 / Aurora）

## 退出情景与敏感性

我们对 Aurora 退出估值做两变量敏感性：P/Sales 倍数（3–11）× 收入 CAGR（20%–50%）。

基期：P/Sales = 7、CAGR = 30%，IRR = 22%。

- 下行情景（CAGR = 20%）：P/Sales = 7 时 IRR = 16%；P/Sales = 3 时 IRR = 9%。
- 上行情景（CAGR = 50%）：P/Sales = 7 时 IRR = 31%；P/Sales = 11 时 IRR = 44%。

我们认为 P/Sales = 5–9、CAGR = 30%–40% 是合理区间，对应 IRR 18%–33%；如出现 CAGR < 25% 的情况，需重新评估投资假设。

限定条件：IRR 按 5 年持有期与 0% 杠杆计算；未计入跨境税务与退出摩擦成本。

证据缺口：

- 退出 P/Sales 倍数的可比公司样本仍偏少（5 家），需 2025 年增补。
