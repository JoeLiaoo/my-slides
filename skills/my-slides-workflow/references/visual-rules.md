# Visual rules

Open before handing the deck to the user for review on 5173. These rules apply per page; `my-slides present --target slides` only runs Design `check --strict`, which does not enforce content or visual quality. The agent catches those issues by comparing each page with `article.md`; the user makes the final call on 5173. For Design's own layout and height-estimation rules, see `<MY_SLIDES_DESIGN_ROOT>/skills/slides/references/design.md`.

## 一、每页一个唯一结论

- 每页只为「一个结论」服务，结论写成页面标题。
- 两个并列结论（如「公司增长快 + 估值便宜」）要么拆页、要么二选一。
- 反例：一页同时出现「增长曲线」「市场份额图」「风险因素列表」，让读者自己拼结论。
- 修正：把次要结论放进脚注或单独一页；让主视觉占据一半以上的版面。
- 仅章节收束页和用户点名的关键页显示「我们的判断 / 对投资的含义」作者结论框。嘉宾原话留在证据区，不让引用替作者下判断。
- 「估计」「未核验」「按某口径」等限定集中在来源脚注，一次交代清楚。

## 二、层级与字号档位（1920×1080 画布）

| 文本角色 | 字号 |
| --- | --- |
| 页面标题 | 56–80px（封面可到 96px） |
| 关键数字 | 64–120px |
| 正文、列表、表格 | 28–36px，不小于 24px |
| 副标题、图内标签 | 26–32px |
| 来源脚注 | 24px |

- 一页的字号档位不超过四档；相邻档位至少差 1.25 倍。
- 标题不超过两行；超长标题拆成主标 + 副标。

## 三、数字、单位、日期、来源贴近结论

- 每个关键数字旁带单位（亿元 / % / 万 / 倍）；日期口径写在数字附近或脚注。
- 外部来源用一行统一格式：`机构或作者《标题》（日期）`；估计和口径紧接该来源说明一次。
- 图表数字必须能在正文或其可核对来源中找到，单位、期间和口径一致。
- 反例：所有来源集中堆在一个「参考资料」框里，正文数字都没有出处。

## 四、先拆页，再缩字号

- 一页装不下时：先删条目或拆页，再考虑缩字号；正文不低于 24px。
- 不要依赖 Design 的 `data-fit` 自动缩字来塞内容：缩到六成的正文在投影上读不清。
- 反例：12 条要点挤在一页。修正：拆成两页，每页 4–6 条。

## 五、关系类型与主视觉一致

- 时间序列用折线；份额用堆叠条；对比用并列柱、哑铃或表格；机理用流程图；风险用矩阵或情景表（见 `references/charts.md`）。
- 反例：用饼图比较两年的市场份额。修正：换成 100% 堆叠条，标出变化超过 2pp 的类别。

## 六、阅读顺序与视线引导

- 页面上真实存在 2–4 个停留点，按标题 → 主视觉 → 结论 / 脚注的顺序排。
- 用字号、位置、留白形成节奏；并列两图时说明先看哪一侧。

## 七、对比与重点

- 只给 1–2 个关键数字或一行数据用强调色；其余保持中性色。
- 反例：所有数字都加粗、大字号，重点不明。

## 八、留白与对齐

- 页面四周留白通常 128px；元素之间用 `gap`，不要贴边或互相压住。
- 同一列左对齐；钉住的元素坐标对齐到同一组网格线。

## 九、图标与装饰

- 图标只用 Design 内置的 `<x-icon>` 名称；不用 emoji 或字体里没有的符号（✓ ✗ ★）。
- 一个图标只承载一个含义；不为装饰而加图。

## 十、自查清单（交给用户审阅前过一遍）

- [ ] 一页只承载一个结论，标题就是结论
- [ ] 正文不小于 24px，字号档位清楚
- [ ] 数字带单位、日期口径、来源脚注
- [ ] 内容过多时拆了页，而不是缩字
- [ ] 关系类型 → 主视觉对应
- [ ] 阅读顺序与停留点存在
- [ ] 只有 1–2 处强调
- [ ] 留白充足，没有元素重叠或出界
- [ ] 每个数字都能在正文或其来源中找到；缺的写成 `[待补：…]`

## 版式多样性与单页信息密度评分

交给用户审阅前逐页打两个 1–5 分，并在交付说明里各写一句证据。以《开源破局》为编辑参照：页面以清楚的主张为中心，文字、图表与结构关系共同承担论证；密度来自相关信息的组织，不来自重复数字或装饰元素。

### 版式多样性（deck 级）

- **5**：版式服务于内容类型；时间、比较、列表/矩阵、趋势、案例、收束使用明显不同且合适的结构；无超过两页的同版式连排。
- **4**：有清楚的版式节奏，少数相似页但主视觉或阅读路径不同。
- **3**：至少 `min(3, 总页数)` 种版式，部分相邻页仍像同一模板。
- **2**：大半 deck 重复同一结构，或版式与内容关系不匹配。
- **1**：几乎每页复用同一模板，读者无法从结构判断页面任务。

### 单页信息密度（逐页）

- **5**：一条明确结论；主视觉承载关键证据；相关次级信息在表格/图示中紧凑分组，阅读顺序清楚，仍有足够留白。
- **4**：结论和证据紧密对应，信息充分且易扫读；局部可以再精简。
- **3**：信息可读，主次略平，或少量内容与结论关联较弱。
- **2**：页面偏空或拥挤；证据孤立、重复，读者需自行拼接关系。
- **1**：一页混合多个无关结论、数字重复凑数或文字/图表挤到难以阅读。

交付建议：deck 版式多样性至少 3 分，每页密度至少 3 分；任一页低于 3 分先调整结构、删减或拆页，再交给用户。
