# Issue #45: current policy and superseded requirements

Issue [#45](https://github.com/JoeLiaoo/my-slides/issues/45) proposed author judgment boxes, numbers, and source footnotes on every content page. The project now has a more selective policy in the current Spec and Slides references. This note records which parts remain in force and which requirements are superseded, so future changes do not reintroduce the older all-pages rule.

| Issue #45 proposal | Current policy |
| --- | --- |
| Put an investor judgment box on every content page. | Keep author ownership clear, but show the judgment box on a key page or a chapter conclusion / judgment page. Repeating it on every page is not required. |
| Put at least one number or chart on every content page. | Research and cite numbers from the validated number list when they support a page. A page can remain qualitative; one number ID is used at most once across the deck. Charts only use listed values. |
| Research public numbers and normalize the source footer. | Evidence research and the standard source footer remain part of the workflow. The footer format is `机构或作者《标题》（日期）`; mark scope, estimate, or verification status there when relevant. |

The selective page requirements are documented in [Spec references](../../skills/my-slides-workflow/references/spec.md), [Slides references](../../skills/my-slides-workflow/references/slides.md), and [visual rules](../../skills/my-slides-workflow/references/visual-rules.md). Issue [#38](https://github.com/JoeLiaoo/my-slides/issues/38) established the current evidence and visual QA workflow. Issues [#49](https://github.com/JoeLiaoo/my-slides/issues/49) and [#50](https://github.com/JoeLiaoo/my-slides/issues/50) add reusable investment components and the executable editorial-light profile without changing the selective judgment rule.

This issue is superseded for the all-pages requirements. Its compatible source formatting and evidence-list requirements are implemented by the current references and validators. No generated deck was rebuilt as part of documenting this policy.
